# Маг Иероглифов — сайт игры

Статический сайт для игры-тренажёра китайских иероглифов.
**Серверная часть не нужна:** всё работает в браузере, никаких сборок, баз данных и зависимостей.
Папку `hanzi-site` можно целиком положить на любой хостинг.

## Что внутри

```
hanzi-site/
├── index.html                 лендинг: описание + игра во встроенном окне (готов к публикации)
├── _template.html             шаблон для пересборки index.html (с заглушками {{CHARS}} и {{SHOWCASE}})
├── favicon.svg                иконка (векторная, 1 файл)
├── css/style.css              оформление сайта
├── js/
│   ├── i18n.js                словари интерфейса сайта: русский / английский / китайский
│   └── site.js                 переключатель версий и языка, ленивая загрузка, полный экран
└── game/
    ├── hanzi-data.js          500 иероглифов (общие данные для обеих версий)
    ├── i18n.js                 словари интерфейса игры
    ├── hanzi-gloss-zh.js       китайские значения 500 иероглифов
    ├── classic/index.html    классическая версия — 6 противников
    └── anime/
        ├── index.html        аниме-версия — 30 врагов и 7 боссов
        ├── enemies-anime.js  арт и данные противников
        └── enemies-anime-i18n.js  английские и китайские имена противников
```

На странице две версии игры: **классическая** и **аниме** — переключаются кнопками,
выбор запоминается в адресе (`#anime`, `#classic`), поэтому ссылку можно передать другому.

## Пересборка

`index.html` **не правят руками** — его собирает `build-site.js` из корня рабочей папки:

```powershell
node build-site.js
```

Сборка копирует игру и файлы локализации в `game/`, перенаправляет пути к данным
на `../hanzi-data.js` и подставляет в `_template.html` стену иероглифов (90 знаков)
и витрину противников (6 фигур). Если правки нужны в разметке — правьте
`_template.html`, а не `index.html`: следующий запуск сборки перезапишет `index.html`.

> В `_template.html` обязаны остаться заглушки `<!--{{CHARS}}-->` и `<!--{{SHOWCASE}}-->`.
> Если сохранить шаблон из уже собранной страницы, заглушки пропадут, и сборка
> не обновит стену и витрину — скрипт теперь сообщает об этом ошибкой.

## Языки интерфейса

Сайт и игра переводятся на **русский, английский и китайский**. Переключатель — в шапке сайта
(Рус / Eng / 中文) и в самой игре.

Язык выбирается в таком порядке:

1. параметр адреса `?lang=en` (или `ru`, `zh`) — им же пользуется игра внутри страницы;
2. сохранённый выбор в `localStorage` (ключ `hanzi.lang`) — общий для сайта и игры,
   поэтому выбранный язык держится и после перехода на другую страницу;
3. язык браузера (`zh-CN` и подобные дают китайский);
4. если ничего не подошло — русский.

Переключение в шапке сайта сразу перерисовывает тексты и **перезагружает игру внутри
страницы с нужным `?lang=`**, так что интерфейс везде совпадает. Названия иероглифов
показываются на выбранном языке: у знака есть русское и английское значение из
`hanzi-data.js`, а китайское добавляет `hanzi-gloss-zh.js`.

Отдельные языковые версии файлов не нужны: словари лежат в `i18n.js`, разметка помечена
атрибутами `data-i18n` / `data-i18n-title` / `data-i18n-aria`, а тексты в коде берутся
через `t("ключ")`.

Стена иероглифов и витрина противников собираются при сборке, поэтому их подписи
`data-i18n` не покрывает: у каждого знака лежат подсказки в `data-t-ru` / `data-t-en` /
`data-t-zh`, а у каждой фигуры — имя, пояснение и ступень на трёх языках. `js/site.js`
показывает нужные при смене языка — иначе эти блоки остались бы русскими.

## Как посмотреть локально

Просто открыть `index.html` двойным щелчком — сайт работает и через `file://`.
Но чтобы проверить всё точно так, как будет в сети, лучше поднять локальный сервер:

```powershell
# любой из вариантов
python -m http.server 8099 --directory hanzi-site
npx serve hanzi-site
```

Затем открыть <http://127.0.0.1:8099/>.

Для проверки можно взять любой статический сервер, например `python -m http.server`.

## Как опубликовать

Файлы уже готовы к публикации — **шаг сборки не нужен**. Загружать нужно *содержимое*
папки `hanzi-site`, чтобы `index.html` оказался в корне сайта.

### Вариант 1. Netlify Drop — самый быстрый

1. Открыть <https://app.netlify.com/drop>.
2. Перетащить папку `hanzi-site` в окно браузера.
3. Через несколько секунд получите адрес вида `https://имя-сайта.netlify.app`.

Регистрация нужна только чтобы сайт остался навсегда.

### Вариант 2. GitHub Pages — бесплатно и надолго

```bash
cd hanzi-site
git init
git add .
git commit -m "Маг Иероглифов: сайт игры"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту сайт будет доступен по адресу `https://ПОЛЬЗОВАТЕЛЬ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

### Вариант 3. Vercel или Cloudflare Pages

Обе площадки умеют «перетащить папку» или подключить репозиторий:

- Vercel: <https://vercel.com/new> → Import → Framework Preset: **Other** → Deploy.
- Cloudflare Pages: <https://dash.cloudflare.com> → Workers & Pages → Create → Pages → Upload assets.

Команда сборки не нужна, каталог вывода — корень (`/`).

### Вариант 4. Обычный хостинг или свой сервер

Скопировать содержимое `hanzi-site` в корень сайта, например в `/var/www/hanzi-site`.
Пример конфигурации nginx:

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/hanzi-site;
    index index.html;

    location / { try_files $uri $uri/ =404; }

    # данные игры весят 250 КБ — стоит кэшировать
    location ~* \.(js|css|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

**Включите сжатие** (gzip или brotli): `hanzi-data.js` и `enemies-anime.js` — это текст,
и сжатие уменьшает их примерно втрое.

```nginx
gzip on;
gzip_types text/css application/javascript image/svg+xml text/html;
```

## Настройки

**Какая версия открывается по умолчанию.** В `js/site.js` найдите функцию `versionFromUrl`
и поменяйте последнюю строку `return "anime";` на `return "classic";`.
Заодно в `index.html` перенесите `aria-selected="true"` на нужную кнопку
и поправьте подпись в `<b id="versionPill">`.

**Свой домен.** У Netlify, Vercel и GitHub Pages он подключается в панели управления.
Если домен внешний — добавьте CNAME-запись на выданный площадкой адрес.

**Звук.** Браузеры запрещают автозвук до первого действия пользователя, поэтому музыка
в игре включается после первого клика по игровому полю. Это нормально и так задумано.

Музыка в каждой версии своя. **Классическая** играет китайскую классику на традиционных
инструментах (古筝, 笛子, эрху, 编钟): 茉莉花, 十面埋伏, 二泉映月. **Аниме** — J-rock
в стиле опенинга: перегруз гитары, синтезатор соло, рок-барабаны, королевский ход
王道進行 (IV → V → iii → vi). Три темы: бой, босс (быстрее) и концовка проигрыша
(фортепиано со струнными, звучит один раз). Всё синтезируется в Web Audio —
аудиофайлов нет, страница остаётся лёгкой.

## Как обновить игру

Игра живёт в папке `hanzi-trainer/`. После правок в ней нужно обновить копии на сайте:

```powershell
node build-site.js
```

Скрипт `build-site.js` (в корне рабочей папки) заново копирует обе версии игры,
поправляет пути к общим данным, добавляет встроенной игре отправку высоты родительской
странице и пересобирает `index.html` вместе с витриной иероглифов и противников.

Сами файлы игры в `hanzi-trainer/` при этом не изменяются — сайт только читает их.

## Технические детали

- **Размер:** около 625 КБ без сжатия, из них 250 КБ — словарь и 99 КБ — арт противников.
  После gzip — примерно 200 КБ.
- **Зависимостей нет:** ни фреймворков, ни шрифтов из интернета, ни аналитики, ни cookies.
  Сайт открывается даже без сети, если файлы уже загружены браузером.
- **Игра во встроенном окне** загружается лениво — только когда посетитель докрутит до неё.
- **Высота окна** подстраивается под игру: она отправляет свой размер родительской странице
  через `postMessage`, поэтому внутренней прокрутки не появляется. Если сообщение не придёт,
  сработает запасное значение (900 px, на узких экранах — 640 px).
- **Полный экран** — кнопкой «Полный экран» или клавишей `F`, когда фокус внутри игры.
- **Совместимость:** Chrome, Edge, Firefox, Safari. На планшете и телефоне игра
  раскладывается в одну колонку и рисуется пальцем.
